# 작업 기록 (Worklog)

그날 한 작업은 `docs/worklog/YYYY-MM-DD.md` 한 파일에 기록한다. (예: `docs/worklog/2026-11-16.md`)

- 하루에 파일 하나. 같은 날 추가 작업은 같은 파일에 이어서 적는다.
- 기록 항목: 기능/화면별 최종 동작, 의사결정과 변경 이력, 변경한 주요 파일, DB 변경, 알려진 제약, 배포 전 필요한 작업(마이그레이션·빌드 등), 검증 상태.
- 작업이 끝났을 때 사용자가 기록을 요청하면 작성한다. 자동으로 push하지 않고, push는 사용자가 요청할 때만 한다.

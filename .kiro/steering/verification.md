# 검증 정책 (Verification Policy)

이 프로젝트에서는 **코드 변경 후 자동 검증 단계를 생략한다.**

- 코드/파일을 수정한 뒤 빌드, 컴파일, 린트, 포매터, 테스트를 **먼저 실행하지 않는다.**
  - 예: `npm run build`, `npm run dev`, `php artisan test`, `vendor/bin/pint`, `php -l` 등을 변경 확인 목적으로 자동 실행하지 않는다.
- 변경사항을 적용한 뒤에는 **무엇을 바꿨는지만 간단히 요약**하고 턴을 마친다.
- 사용자가 명시적으로 "빌드해줘", "테스트 돌려줘", "검증해줘"라고 요청할 때에만 해당 명령을 실행한다.
- 검증을 생략했다는 사실을 매번 길게 설명하거나 사용자에게 검증 여부를 되묻지 않는다.
- DB 관련/파괴적 명령(`migrate`, `migrate:fresh`, `db:seed` 등)은 기존 보안 규칙대로 여전히 사용자의 명시적 승인이 있을 때에만 실행한다.
